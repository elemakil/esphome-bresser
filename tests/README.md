# Decoder tests

`run_golden.py` checks that the decoder in `components/bresser/bresser_decoder.cpp` produces
the same readings as rtl_433's `bresser_7in1.c`, from which it is ported.

```sh
python3 tests/run_golden.py
```

It builds `decoder_cli.cpp` with `g++ -std=c++17 -Wall -Wextra -Werror` into `build/tests/`,
feeds it every payload in `golden/bresser_golden.jsonl` and compares the output with rtl_433's.
Every measurement must match in presence and value (absolute tolerance 1e-3), as must `id`,
`battery_ok`, `startup`, the model, and `channel` where rtl_433 reports it. rtl_433's
`light_klx` (lux / 1000) and `mic` are not compared. The script prints a pass/fail count per
vector source and exits non-zero on any mismatch.

## The golden file

`golden/bresser_golden.jsonl` was generated by running rtl_433's `bresser_7in1.c` at commit
[`15ac67bc9ee709a6fb0eb1e69cc660c7e43997ac`](https://github.com/merbanan/rtl_433/tree/15ac67bc9ee709a6fb0eb1e69cc660c7e43997ac)
on each payload. The first line is a `#` comment; every other line is one JSON object:

```json
{"source": "...", "hex": "<payload>", "expect": <rtl_433's JSON output, or null if it rejected the payload>}
```

`hex` is the radio payload: the bytes after the `2D D4` sync word, as the radio delivers
them. There are 1556 vectors:

- **corpus**: frames recorded from a real 7-in-1 weather station.
- **synthetic**: generated frames with valid digests that exercise every sensor type,
  edge cases of every field (negative temperatures, BCD digits out of range, the air quality
  sensors' "not measured yet" markers), and unsupported types.
- **reject**: frames that must be rejected (bad digest, raw byte 21 zero, all zeros).

## Decoding a captured frame

`decoder_cli` reads one hex payload per line and prints the reading as JSON, or `null`:

```sh
python3 tests/run_golden.py >/dev/null   # builds build/tests/decoder_cli
echo <hex from the radio's on_packet log> | build/tests/decoder_cli
```
